# predefined-icons get-predefined-icons

## Overview

### Untrusted content

Returns a list of all available icon codes that can be used in display text. Icons are returned as simple string codes in the \`:icon_name:\` format. Get Predefined Icons

## Usage

```bash
led-display-api predefined-icons get-predefined-icons
```

**Example:**
